# Конфигурация приложения

В этом пакете содержится логика загрузки и управления конфигурацией приложения. Конфигурация может быть задана через файлы конфигурации (YAML, .env), переменные окружения или флаги командной строки.

## Флаги запуска

Приложение поддерживает следующие флаги командной строки:

*   `-config`: Путь к файлам конфигурации. Можно указать несколько файлов через запятую. Поддерживаются файлы `.env` и `yaml` (или другие форматы, поддерживаемые viper, если указано расширение).
    *   Пример: `-config=.env.local,config.yaml`
    *   Если файл имеет расширение `.env` или начинается с `.env`, он загружается через `godotenv`.
    *   Остальные файлы загружаются через `viper`.

## Загрузка конфигурации

Конфигурация загружается в следующем порядке (приоритет от низшего к высшему):

1.  **Значения по умолчанию**: Заданы в коде (см. таблицу ниже).
2.  **Файлы конфигурации**: Указанные через флаг `-config`. Загружаются в порядке перечисления.
3.  **Переменные окружения**: Автоматически подхватываются переменные, соответствующие ключам конфигурации (разделитель `.` заменяется на `_`, регистр не важен). Например, `POSTGRES_HOST` → `postgres.host`.

## Параметры конфигурации

Конфигурация разделена на секции. Ниже приведен список доступных параметров и их значений по умолчанию.

### Секция `log` — Логирование

| Параметр | Ключ в конфиге | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| Level | `log.level` | string | `trace` | Уровень логирования (`trace`, `debug`, `info`, `warn`, `error`, `fatal`, `panic`). |
| IsLogInFiles | `log.is_log_in_files` | bool | `true` | Включить запись логов в файл. |
| Filename | `log.filename` | string | `./logs/app.log` | Путь к файлу логов. |
| MaxSize | `log.max_size` | int | `5` | Максимальный размер файла лога в МБ до ротации. |
| MaxBackups | `log.max_backups` | int | `4` | Максимальное количество старых файлов логов для хранения. |
| MaxAge | `log.max_age` | int | `360` | Максимальное количество дней хранения старых файлов логов. |
| Compress | `log.compress` | bool | `false` | Сжимать ли старые файлы логов. |

### Секция `app` — Приложение

| Параметр | Ключ в конфиге | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| Mode | `app.mode` | string | `debug` | Режим работы приложения (`debug`, `release`). В `release` отключается Swagger/Scalar и включается gin release mode. |
| Port | `app.port` | string | `8080` | Порт, на котором запускается HTTP-сервер. |
| SchedulerEnabled | `app.scheduler_enabled` | bool | `true` | Включить планировщик фоновых задач. |
| KeyForCryptUtils | `app.key_for_crypt_utils` | string | `6368616e...` | Ключ для шифрования/дешифрования строк (секреты приложений, redirect URL и др.). |
| ServiceUrl | `app.service_url` | string | `http://localhost` | Базовый URL сервиса (используется в OIDC discovery и redirect). Если равен `http://localhost`, автоматически подставляется порт. |

### Секция `postgres` — База данных

| Параметр | Ключ в конфиге | Переменная окружения | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Host | `postgres.host` | `POSTGRES_HOST` | string | `localhost` | Хост PostgreSQL. |
| Port | `postgres.port` | `POSTGRES_PORT` | string | `5432` | Порт PostgreSQL. |
| User | `postgres.user` | `POSTGRES_USER` | string | `main` | Пользователь БД. |
| Password | `postgres.password` | `POSTGRES_PASSWORD` | string | `password` | Пароль пользователя БД. |
| Db | `postgres.db` | `POSTGRES_DB` | string | `gd_auth` | Название базы данных. |
| Sslmode | `postgres.sslmode` | `POSTGRES_SSLMODE` | string | `disable` | Режим SSL (`disable`, `require` и др.). |

### Секция `cors` — CORS

| Параметр | Ключ в конфиге | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| AllowedOrigins | `cors.allowed_origins` | string | `http://localhost` | Список разрешённых Origins через запятую. |
